# 用户反馈库

人在外面，微信里收到客户反馈 → 转发给 QQ 机器人 → 自动入库、识别截图文字、归类、提示以前的同类问题和处理办法。

- **不丢**：先落库再回执；断线、重启期间的消息由 QQ 平台补发；附件失败自动重试。**没收到回执就等于没记上。**
- **可分析**：截图/语音里的文字可搜；自动识别分类、产品、版本；同类问题可归并，沉淀原因与方案；可统计、可导出 Excel(CSV)/Markdown/JSON。
- **数据不出公司**：单进程 + SQLite，OCR 本地离线，不调用任何第三方 AI。

## 先体验（不需要 QQ 账号）

```bash
nvm install && nvm use   # Node 22.13+，推荐 24
npm ci
npm run demo             # 终端里打字 = 在 QQ 里发消息；网页 http://127.0.0.1:8799 密码 demo-password
```

## 正式使用

**1. 创建 QQ 机器人**（官方，免费，不会封号）
1. 打开 <https://q.qq.com> 注册并完成主体认证（个人即可），创建「机器人」。
2. 「开发管理」里拿到 **AppID**、**AppSecret**（Secret 只显示一次）。若控制台要求 IP 白名单，填服务器的出口公网 IP。
3. 事件接收方式选 **WebSocket**（不要配 Webhook 回调）。
4. 「沙箱配置 → 消息列表」把自己的 QQ 加进去，扫码添加机器人。只给自己用，留在沙箱即可，通常不必提交上线审核。

> 控制台菜单名称可能调整，以平台页面为准。

**2. 启动**

```bash
cp .env.example .env     # 填 ADMIN_PASSWORD、QQ_APP_ID、QQ_APP_SECRET
npm run doctor           # 自检：凭据、网关、OCR、目录
npm run build && npm start
```

或 `docker compose up -d --build`。服务器不需要公网 IP 和域名，能访问外网即可，但需要**常开**（电脑休眠期间的消息，超过平台补发时限会丢）。
Linux 裸机安装时加 `ONNXRUNTIME_NODE_INSTALL_CUDA=skip npm ci`，避免下载 GPU 组件。

**3. 绑定**：网页后台「设置 → QQ 账号 → 生成绑定码」，把「绑定 12345678」发给机器人。只有绑定过的 QQ 能记录和查询。

## 怎么记

| 微信里收到 | 怎么发给机器人 |
|---|---|
| 文字 | 长按复制 → 粘贴 |
| 图片 / 文件 | 保存或「用其他应用打开」→ QQ 机器人 |
| 一段对话 | 截图（长截图也行），文字会自动识别 |
| 语音 | 微信里转文字后复制，或直接对机器人发 QQ 语音口述 |

连续发的内容 5 分钟内自动并成一条。开头写 `客户：张三`（独占一行）会自动填字段，支持：客户 产品 版本 分类 优先级 来源 标签 标题。

| 指令 | 作用 |
|---|---|
| `新建` / `完成` / `撤销` / `拆分` | 另起一条 / 结束 / 撤回上一条素材 / 上一条素材拆成新反馈 |
| 引用任意消息再发，或 `/补充 12 内容` | 追加到那条反馈 |
| `/客户 张三`、`/产品` `/版本` `/分类` `/优先级` `/标签` `/标题` `/备注` `/状态` | 改当前这条；改别的加 `#编号`：`/客户 #12 张三` |
| `/解决 处理办法` | 标为已解决并记下办法，下次遇到同类会自动提示 |
| `/查 关键词`、`/详情 12`、`/相似 12`、`待处理`、`统计` | 查阅 |
| `/同类 7` | 与 #7 归为同一类问题 |
| `/并入 7` | 与 #7 是同一条反馈，合并 |

认不出的指令一律当反馈记下，不会丢。

## 运维

- **备份**：每天一份 `data/backups/日期.db`。附件在 `data/files`（只增不改），把整个 `data` 目录同步走即可。恢复：停服务，用备份覆盖 `data/feedback.db`（并删掉 `-wal`、`-shm`）。
- **健康检查**：`GET /healthz`；机器人状态看「设置」页。
- **异常消息**：处理出错的原始消息在 `data/deadletter.jsonl`。
- **对外访问**：默认只监听本机。要从外面看后台请走 HTTPS 反向代理，并设 `TRUST_PROXY=true`、`COOKIE_SECURE=true`。

npm test            # 48 项单元/集成测试
