## 验收步骤

**A. 演示模式（5 分钟，不要 QQ）** `npm run demo`
- [ ] 输入「手机收不到验证码」→ 回执带分类，并提示以前同类的处理办法
- [ ] 输入「图 /路径/微信截图.png」→ 标题、分类来自截图文字
- [ ] 输入「同类 2」→ 归类；网页「同类问题」里能看到
- [ ] 网页搜索截图里的某个词 → 能搜到

**Windows 实机**（Windows 10 / 11 x64，最好是没装过开发工具的电脑）
- [ ] 安装：SmartScreen 点「更多信息 → 仍要运行」→ 选目录 → 完成后自动打开封面
- [ ] 引导走完；防火墙弹窗勾「专用网络」；QQ 绑定自动变化
- [ ] 「诊断 → 开始自检」全绿，重点看「截图文字识别」
- [ ] 手机扫码打开；发带图的问题，弹通知，截图文字可搜索
- [ ] 关窗后托盘图标仍在，左键打开、右键有菜单；托盘退出后端口释放
- [ ] 重启电脑：自动在托盘运行、不弹窗口；关机不被拦
- [ ] 再装一次同版本（模拟升级）：数据还在；卸载：数据还在、开机自启已去掉

**手机** 连同一 Wi-Fi 扫「设置 → 手机查看」二维码
- [ ] 能登录，看到历史记录卡片，能搜索、点开看截图

**AI 助手** 「设置 → AI 助手」生成令牌，执行给出的命令
- [ ] 问 Claude「用 tiangong-feedback 查一下以前有没有 xxx 的问题」→ 能查到
- [ ] 在「临时写入授权」填问题编号并签发单问题码，确认页面显示作用范围和到期时间，只复制一次显示的码
- [ ] 让 MCP 使用 `update_issue` 修改指定问题，确认网页详情和操作记录已更新
- [ ] 用同一个单问题码修改别的问题或同类问题，确认返回拒绝且数据库内容不变
- [ ] 签发全部问题码，使用 `update_issue` 和 `update_known_problem`，确认问题与主题更新成功并在 MCP 审计中看到真实授权人和 MCP 来源
- [ ] 撤销授权或等待过期后再次写入，确认拒绝；使用无效 Bearer 令牌确认身份校验先于写入

**B. 真实 QQ** 按 README 配置后 `npm run doctor` 全绿
- [ ] 设置页显示「在线」，绑定成功
- [ ] 在外用手机流量发文字 + 2 张截图 → 只回一次，网页里是一条
- [ ] 发「提交：测试问题」→ 另起一条，网页和 MCP 都能查到
- [ ] 隔 5 分钟以上再发 → 另起一条
- [ ] 引用旧消息补充 → 追加到原反馈
- [ ] 停掉服务，发一条，1 分钟内启动 → 能补收
- [ ] 用没绑定的 QQ 发 → 被拒绝且没有记录
