## 没有条件验证，需要你来确认

1. **真实 QQ 收发**（需要你的 AppID/Secret）：文字、图片、语音、引用、重启服务后补发。测试用的是按官方文档写的模拟平台。
2. **合并转发的聊天记录**：官方文档列了这个类型，但没写是否下发正文。收不到正文时机器人会提醒改用截图。
3. **Docker 镜像**：本机 Docker 未运行，没有实际构建过。

## 验收步骤

**A. 演示模式（5 分钟，不要 QQ）** `npm run demo`
- [ ] 输入「手机收不到验证码」→ 回执带分类，并提示以前同类的处理办法
- [ ] 输入「图 /路径/微信截图.png」→ 标题、分类来自截图文字
- [ ] 输入「同类 2」→ 归类；网页「同类问题」里能看到
- [ ] 网页搜索截图里的某个词 → 能搜到

**B. 真实 QQ** 按 README 配置后 `npm run doctor` 全绿
- [ ] 设置页显示「在线」，绑定成功
- [ ] 在外用手机流量发文字 + 2 张截图 → 只回一次，网页里是一条
- [ ] 隔 5 分钟以上再发 → 另起一条
- [ ] 引用旧消息补充 → 追加到原反馈
- [ ] 停掉服务，发一条，1 分钟内启动 → 能补收
- [ ] 用没绑定的 QQ 发 → 被拒绝且没有记录
